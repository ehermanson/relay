The `file_unchanged` variant of `FileReadOutput` was removed from `sdk-tools.d.ts` in Claude Agent SDK 0.3.317 (Claude Code CLI 2.1.318). Re-reading an unchanged file now returns its full content rather than a stub signal. Any Relay code that checks for this variant — in transcript parsing, activity rendering, or tool-result handling — will fail to compile or behave incorrectly after the next SDK upgrade.

Bucket: Breaking/deprecation (0) — priority 1.

Relay touchpoints: `server/core/providers/claude-sdk.ts`, `server/core/providers/claude-transcript.ts`, any code that pattern-matches on `FileReadOutput` variants.

Scope: audit for `file_unchanged` checks; remove or replace with the now-uniform full-content result. Small change once located.
