Agent SDK 0.3.234 removed `bypass_permissions_disabled` from the `ExitReason` union type. If any Relay code references this value — in switch exhaustiveness checks, string comparisons, or `as ExitReason` casts — it will fail to compile or silently behave incorrectly on the next SDK pin bump.

Needed:
1. Search `server/core/providers/claude-sdk.ts` and surrounding types for any reference to `'bypass_permissions_disabled'` or an import of `ExitReason` that could carry the removed variant.
2. Update any switch statements covering `ExitReason` values to remove the dead arm and verify exhaustiveness.
3. Note: our SDK deps are pinned, so this is a heads-up for the next upgrade, not a currently-broken state.

Scope: small (~30 min audit). Touch point: `claude-sdk.ts`, any TypeScript type that mirrors `ExitReason`.

Bucket 0 — priority 1.
