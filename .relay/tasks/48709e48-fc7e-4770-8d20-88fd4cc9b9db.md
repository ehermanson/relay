Agent SDK 0.3.305 adds `recommendations` (text advice) and `fix` (actionable steps) fields to each behavior window in the `get_usage` snapshot response. Relay already polls `get_usage` (via `refreshUsageRateLimits` in `claude-sdk.ts`) for plan utilization; those fields are currently not surfaced.

When a chat hits a usage limit or is approaching one, showing the `fix` text directly in the rate-limit banner or tooltip would let users act without leaving Relay. `recommendations` can provide secondary context.

1. Read `recommendations` and `fix` from `get_usage` behavior-window entries in `claude-sdk.ts`.
2. Pass them through to `ProviderRateLimitWindow` (or a new type field).
3. Render the `fix` text in the rate-limit warning chip / panel — one concise line with an expand affordance if long.

`recommendations` and `fix` are new optional fields; gate them with `?.` so older CLIs are unaffected.

Scope: small (~1.5h). Touch points: `claude-sdk.ts` (get_usage reader), rate-limit types, rate-limit banner/chip UI.
