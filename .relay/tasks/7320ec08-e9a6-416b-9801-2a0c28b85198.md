The `@anthropic-ai/sdk` TypeScript package released version 1.0.0 on 2026-10-21, a major version bump that bumps the Anthropic API version from the prior default to **2026-10-21**. The changelog marks this as a breaking change. Relay pins `@anthropic-ai/sdk` at `0.109.0` in `package.json`; the `@anthropic-ai/claude-agent-sdk` dependency (pinned `^0.3.273`) also depends on this package internally.

Before upgrading either SDK, someone needs to audit what changed in API version 2026-10-21:

- Check the Anthropic API reference for what the new API version adds, removes, or changes in response shapes (message object, streaming events, tool call formats, error payloads).
- Verify that `claude-sdk.ts` does not rely on any removed/renamed response fields.
- Check whether the Agent SDK's own 0.3.304–0.3.310 releases bundle a 1.x SDK internally and already expose the new API version to the CLI; if so, Relay's own pinned SDK is already out of sync.
- Versions 0.136.0 and 0.137.0 preceded 1.0.0 and added analytics/webhook fields — those are low-risk. The 1.0.0 bump itself is the audit target.
- Subsequent releases 1.1.0–1.3.0 add User Profile enforcement, message threads, usage reports by dimension, and Claude Tag endpoints; none are breaking.

Scope: audit (~1h); any actual migration work is separate.
