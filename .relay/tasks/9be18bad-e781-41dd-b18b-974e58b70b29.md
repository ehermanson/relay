SDK versions 1.10.0–1.12.0 (all in the upgrade path from Relay's current 0.109.0) added several new error codes that Relay should recognize and surface to users: contract_spend_limit_reached and billing refusal codes (1.10.0), user_profile_billing_not_authorized (1.10.0), sandbox_egress_restricted (1.11.0), and image_dimensions_too_large (1.12.0). Without handling, these surface as generic errors with no actionable message in the UI. Scope: add the new codes to Relay's error classification and display them with appropriate user-facing copy in the chat error state. Source key: anthropic-sdk/1.10.0+1.11.0+1.12.0/new-error-codes.
