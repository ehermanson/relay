Claude Code 2.1.312 added `permissions.blockWritesOutsideWorkingDirectories`: when set, Write, Edit, and NotebookEdit refuse paths outside the working directories in every permission mode.

**What Relay needs to do:** expose this as an opt-in session permission in `ProviderCapabilities` so Relay can pass it to Claude during session creation. This is a capability-declaration addition — a boolean flag that maps to a settings key in the Claude session arguments.

**Touches:** `ProviderCapabilities`, Claude driver session settings, and the session-options section of the UI.

**Scope:** small — a boolean settings key, a capability flag, and a toggle in the UI session config.

**Bucket:** capability-declaration (bucket 2).
