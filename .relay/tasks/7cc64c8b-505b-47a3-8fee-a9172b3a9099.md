Claude Agent SDK 0.3.319 added support for MCP tasks (`task_type: "mcp_task"`): when an MCP server runs a tool call as a task, Claude Code moves it to the background and reports the result when it finishes. This is a new value for the `task_type` field on task events. Relay processes task events in `server/core/providers/claude-sdk.ts` and classifies them in `server/core/agent-messages.ts`; the distinction between agent tasks and `local_bash`/`mcp_task` tasks matters because only agent-shaped tasks map to `AgentInfo`.

Bucket: Capability-declaration (2) — priority 2.

Relay touchpoints: `server/core/providers/claude-sdk.ts` task event handling, `server/core/agent-messages.ts` task classification. Per CLAUDE.md: "Not every background task is an agent — `local_bash` tasks emit the same `task_*` events — so a task event maps to an agent only when its `tool_use_id` is an already-known agent key." `mcp_task` follows the same non-agent path as `local_bash` and must be classified accordingly.

Scope: add `mcp_task` to the non-agent task-type list; verify it doesn't create spurious AgentInfo entries. Small.
