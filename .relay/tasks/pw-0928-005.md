Agent SDK 0.3.282 adds two alpha prewarming APIs: `prewarm()` (start a spare process in the background) and `SpareProcess.claim()` (claim a prewarmed process for an immediate session start). These are designed to eliminate the startup delay users perceive when creating a new chat.

Relay already has a prewarm concept (`prewarmSdk` in `claude-sdk.ts`), but the current approach re-does the full SDK startup on every new session. With `SpareProcess.claim()`, a pre-started Claude process can be promoted to an active session in one step, saving the ~2s startup gap.

This is marked **alpha** — do not ship to production until the API stabilises, but evaluate now and design the integration.

Needed:
1. Read the `prewarm()` / `SpareProcess.claim()` API contract in `@anthropic-ai/claude-agent-sdk` 0.3.282.
2. Audit `claude-sdk.ts` `prewarmSdk` and `createInstance` to understand where `SpareProcess.claim()` would hook in.
3. Determine whether `claim()` passes an already-resolved `configDir` and `managedSettings` or needs re-injection, and whether it's compatible with multi-account profiles.
4. Prototype integration behind a `RELAY_PREWARM_SPARE=1` flag; do not touch the production prewarm path until the API is stable.

Scope: medium (~3h design + prototype). Stability risk: alpha — needs re-evaluation on stabilisation.
