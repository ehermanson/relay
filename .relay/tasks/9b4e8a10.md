Claude Code CLI 2.1.248 adds a `--restricted` flag that launches sessions with command-execution and code-running tools removed and file access confined to the working directory. This is a tighter sandbox than `approval-required` (which still prompts for every tool call) and is aimed at read/analysis workloads where execution capability is undesirable.

Relay's `ProviderRuntimeMode` currently covers `approval-required | full-access | plan`. `restricted` is a new peer mode that should be added as:
1. A new `'restricted'` value in `ProviderRuntimeMode`.
2. An entry in `ProviderCapabilities.runtimeModes` for Claude with label, description, and icon.
3. Mapping in `claude-sdk.ts` to the SDK session arg that triggers restricted mode (likely `permissionMode: 'restricted'` or a dedicated flag — confirm from SDK types).
4. DB migration if `ProviderRuntimeMode` is stored as an enum column.

Scope: small (~1–2h). Touch points: `server/core/types.ts`, `claude-sdk.ts`, `ProviderCapabilities`, runtime-mode picker UI.

Bucket 2 — priority 2.
