Agent SDK 0.3.247 adds an optional `ambient` boolean to `task_started`, `task_notification`, and `background_tasks_changed` events. When `ambient: true`, the task is routine housekeeping (e.g. internal bookkeeping, background maintenance) that hosts should silently suppress from user-facing activity indicators. When absent or false, the event is meaningful and should surface normally.

Relay's sidecar and activity panels forward all task events indiscriminately today. Adding ambient-filtering prevents meaningless housekeeping entries from polluting the Tasks sidecar and the activity timeline.

Needed:
1. In `claude-sdk.ts`, check `ambient === true` on task events before forwarding to the activity stream; skip ambient events.
2. Verify the field is present on all three event types in the installed SDK version (0.3.247+).

Scope: small (~30 min). Touch points: `claude-sdk.ts` (task event handlers).

Bucket 2 — priority 2.
