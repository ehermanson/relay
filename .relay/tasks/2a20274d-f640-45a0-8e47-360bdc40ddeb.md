Codex 0.159.0 (released 2026-09-29) adds an opt-in `instant_interrupt` feature. When enabled, new input redirects a running Codex agent mid-response or mid-code-mode call without waiting for the current operation to complete.

This is analogous to Claude Code's interrupt/stop functionality that Relay already surfaces. If `instant_interrupt` is available in app-server mode (needs verification — it may be a TUI-only option), Relay could expose it as a toggleable session capability.

ProviderCapabilities / abstraction: Add `instantInterrupt?: boolean` to Codex's `ProviderCapabilities`, expose as a session option at chat-start time, pass through in `codex app-server` session args.

Needed:
1. Verify that `instant_interrupt` is exposed in app-server protocol (not just the TUI). Check `codex-app-server.ts` and the Codex protocol docs.
2. If confirmed: add `instantInterrupt?: boolean` to `ProviderCapabilities` for the Codex driver.
3. Wire it through to the `codex app-server` session start (alongside existing session options like approval policy).
4. Surface as a toggleable option in session/project settings (analogous to how fast-mode or reasoning effort are presented for Claude).

Scope: Research first (~30 min), then small (~1h) if available in app-server mode.
