Claude Code 2.1.329 changed 'claude mcp add --scope project' to stop (instead of overwriting) when the target project already has a .mcp.json that lists servers at the top level. Relay uses 'claude mcp add' to manage project-scoped MCP servers (mcp-management.ts). For users who already have a .mcp.json with top-level entries, Relay's MCP add call would now fail silently or with an error rather than adding the new server. Scope: update mcp-management.ts to handle the new failure case — either detect the existing top-level format and guide the user, or switch to a merge-safe approach.
