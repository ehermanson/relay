SDK 0.3.214 adds two new fields to `tool_progress` events:
- `subagent_type`: identifies what kind of subagent is running.
- `subagent_retry`: whether this is a retry of a previously failed tool call.

Relay's agents sidecar panel (see also open task `ffbc884b` for the related `blocked` field) shows live agent activity from `workflow_agent` and `tool_progress` events. These fields can enrich it:
- Show subagent-type labels on agent rows instead of generic identifiers.
- Show a retry indicator (badge or icon) on retried tool calls.

Touch points:
1. `claude-sdk.ts`: parse `subagent_type` and `subagent_retry` from `tool_progress` events and forward through `AgentActivity`.
2. Agents sidecar component: render type labels and retry indicator.

Coordinate with `ffbc884b` (blocked field) — consider landing together as a single sidecar-enrichment pass.

Scope: small (~2–3h including UI).

Bucket 2 — priority 2.

Ref: @anthropic-ai/claude-agent-sdk CHANGELOG v0.3.214
