SDK 0.3.329 added 'permissions.workingDirectoriesExclude' to the Settings type, letting a session explicitly exclude specific directories from Claude's write access — a complement to the existing blockWritesOutsideWorkingDirectories option (tracked in task 1d8569d7). Relay should expose this new field in ProviderCapabilities or session creation options so users can restrict write access to specific subdirectories within the project. Scope: add the field to the Claude session creation parameters and surface it alongside the existing write-restriction controls.
