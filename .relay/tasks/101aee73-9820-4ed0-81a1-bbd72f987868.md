## Summary

Anthropic SDK 0.129.0 introduces optional early tool-call execution: tool calls can begin while the assistant's text reply is still streaming, changing the interleaving of text and `tool_use` blocks in the stream.

**Impact on Relay:** Relay's activity group builder and message accumulator in `claude-sdk.ts` currently assume tool calls come after the assistant turn's text completes. If a `tool_use` block starts mid-text, the current builder may misassign it to the wrong turn, split the activity group incorrectly, or display the text as cut off. This is a heads-up for when `@anthropic-ai/sdk` is upgraded from 0.109.0.

**What Relay could do:** Audit the stream accumulator for the assumption that text blocks are complete before tool blocks begin. Add handling for interleaved `tool_use_start` events mid-text.

**Which control this touches:** Stream accumulation in `claude-sdk.ts`, activity group building, message display order.

**Scope:** Medium — requires understanding the accumulator's state machine and adding an interleave-safe path.
