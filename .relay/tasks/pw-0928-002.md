Claude Code 2.1.283 / Agent SDK 0.3.283 fixed a bug where SDK sessions that ended before all deferred tool calls completed (or before all tool results were delivered) would silently lose the pending tool state. In Relay, deferred tool calls appear when Claude launches background agents or dispatches tool work it expects to resume — if the session terminates early (network drop, server restart, SIGKILL during shutdown), those calls were silently discarded.

The symptom: agent cards that never transitioned from "running" to a terminal state, or tool results that disappeared without being matched, on sessions that ended unexpectedly. Relay would then replay the transcript without the result and show an incomplete agent outcome.

This bug is present in all SDK versions Relay currently pins. The fix shipped in SDK 0.3.283 / CLI 2.1.283.

Needed:
1. Upgrade `@anthropic-ai/claude-agent-sdk` to `^0.3.283` (covers this and the control-request leak fix in pw-0928-001).
2. Review `claude-sdk.ts` session teardown path: confirm Relay's cleanup logic matches the new SDK behavior when a session ends with deferred state outstanding.
3. Check transcript replay in `parseJsonl` to ensure partial deferred-call records are handled gracefully (they may appear in transcripts written before the fix shipped).

Scope: small-medium. Touch points: `package.json`, `claude-sdk.ts` teardown, `parse-jsonl.ts` (defensive).
