Claude Agent SDK 0.3.317 added a new `session_writes_lost` system message, emitted after the last result when a full disk or storage quota prevented saving the session transcript or `~/.claude.json`. Relay parses system messages and routes them to the UI. Without handling, this message will fall through as an unrecognized type.

Bucket: Capability-declaration (2) — priority 2.

Relay touchpoints: `server/core/providers/claude-sdk.ts` system message handling, `server/core/providers/agent-messages.ts` message classification, UI system-event display (`session_writes_lost` should surface as a visible warning: session not persisted, user may lose history on restart).

Scope: add the new message type to the system-message classifier; add a UI system event for it. Small.
