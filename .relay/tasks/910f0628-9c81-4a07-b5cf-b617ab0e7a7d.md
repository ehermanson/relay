SDK 0.3.326 deprecated passing mcpServers on the command line (argv default). A future release switches the default to 'initialize', sending MCP configs in the initialize request. Relay's orchestration injection in claude-sdk.ts uses argv delivery; when the default changes, agents lose access to Relay's orchestration tools. Scope: add mcpServersDelivery: 'initialize' to SDK spawn options in claude-sdk.ts and verify bearer token still arrives. Source key: claude-agent-sdk/0.3.326/mcpServers-argv-deprecated.
