SDK 1.9.0 introduced a stricter parser for streamed tool input: any content that is not valid JSON (e.g. comments, trailing text) now fails with an error instead of being accepted leniently. Relay processes streamed tool calls from Claude via the agent SDK, which wraps the Anthropic SDK. When Relay next upgrades through 1.0.0 to 1.9.0+, any tool call whose input contains non-JSON text would throw during streaming, potentially crashing or stalling a session turn. Scope: review claude-sdk.ts streaming tool-input handling and add a safeguard for parse errors. Source key: anthropic-sdk/1.9.0/streaming-tool-input-strict-json.
