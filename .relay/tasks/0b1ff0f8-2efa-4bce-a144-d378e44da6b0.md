Anthropic SDK 1.4.0 added two new session error types: `tool_use_limit_reached_error` and `compaction_limit_reached_error`. These can appear in session events when a session hits tool-use or compaction limits. Relay's rate-limit and session-error handling in `server/core/providers/claude-sdk.ts` does not yet recognize these variants, so they will fall through as unknown errors rather than surfacing actionable state to the user.

Bucket: Breaking/deprecation (0) — priority 1 (heads-up for next SDK upgrade; pinned SDK is currently 0.109.0 so this is not yet live, but the upgrade path is clear).

Relay touchpoints: `server/core/providers/claude-sdk.ts` rate-limit event handling, session-error display, `ProviderCapabilities` rate-limit fields.

`compaction_limit_reached_error` is especially relevant because Relay uses autocompaction and surfaces compaction state.

Scope: add the two error type strings to the error-classification switch; propagate to the existing error-state display. Small to medium change.
