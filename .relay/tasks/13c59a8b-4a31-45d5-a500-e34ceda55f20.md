SDK 0.3.327 made query(), startup() and prewarm() throw when their options contain circular references or BigInt values. Relay calls all three paths. If any config object passed to these functions (bootstrap context, model options, session settings) inadvertently contains a circular reference, the call would error on the next SDK upgrade. Scope: audit claude-sdk.ts for all query/startup/prewarm call sites and confirm options are plain-serializable JSON. Source key: claude-agent-sdk/0.3.327/query-options-strict-validation.
