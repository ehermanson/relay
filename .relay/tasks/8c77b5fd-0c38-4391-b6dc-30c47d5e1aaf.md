Model discovery (prewarm + refreshSdkDiscoveredModelsIfStale in claude-sdk.ts) probes only the default profile's config dir, so the model picker shows the default account's models for every chat. Enterprise accounts expose a different list. Key the SDK-discovered model cache by config dir, probe each profile (lazily, on first use, with the same 30-min TTL), and have GET /api/provider-models accept a profileId (or resolve from the chat's configDir) so the picker, project settings and global defaults show the right list per account. Keep BUILTIN_PROVIDER_MODELS as the offline fallback.
