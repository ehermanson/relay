Agent SDK 0.3.246 adds a `perTaskStopAffordance` session option. When enabled, the stop/interrupt action aborts only the currently-running foreground task while leaving background agents running — a finer-grained interrupt than today's all-or-nothing cancel.

Relay's chat toolbar currently has a single stop button that calls `interrupt()` on the SDK session, which halts everything. With `perTaskStopAffordance`, Relay could offer two interrupt behaviors:
- **Stop current task** (new): cancel only the foreground task, leave background agents.
- **Stop all** (existing): halt everything, as today.

Needed:
1. Set `perTaskStopAffordance: true` in the Claude session start options in `claude-sdk.ts`.
2. Add a `stopCurrentTask()` method on the session driver alongside the existing `interrupt()`.
3. Add `perTaskStop?: boolean` to `ProviderCapabilities` so the UI can render the two-button stop affordance only when the provider supports it.
4. Update the stop button UI in the chat toolbar to show the split affordance.

Scope: medium (~2–3h). Touch points: `claude-sdk.ts`, `ProviderCapabilities`, chat toolbar.

Bucket 2 — priority 2.
