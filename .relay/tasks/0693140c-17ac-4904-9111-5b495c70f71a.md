SDK 1.10.0 renamed several error data model types (the old names are deprecated with a note that they will be removed in a future SDK version). Relay references Anthropic SDK types for error handling and display. When the deprecated names are removed in a later upgrade, any code that imports or checks the old type names would fail to compile. Scope: after Relay upgrades through the 1.0.0 baseline, update error type references in the codebase to the new names. Source key: anthropic-sdk/1.10.0/error-data-model-renamed. Changelog: https://github.com/anthropics/anthropic-sdk-typescript/blob/main/CHANGELOG.md
