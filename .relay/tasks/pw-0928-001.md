Agent SDK 0.3.281 fixed a bug where control requests (e.g. interrupt, permission-response) made after `query.close()` would hang indefinitely or leak the underlying transport. Relay makes control requests during active sessions for interrupt, permission approval/denial, and plan continuation. If the query closes concurrently with one of these — due to a network drop, server restart, or session error — the in-flight control request can leave the Node.js process with an open handle and no timeout path.

This bug is present in all SDK versions Relay currently pins (`^0.3.273`). The fix shipped in 0.3.281.

Needed:
1. Upgrade `@anthropic-ai/claude-agent-sdk` in `package.json` to `^0.3.281` or later to pull in the fix (also picks up 0.3.283 fixes below).
2. After upgrade: smoke-test interrupt + permission-response during a session that disconnects mid-turn to confirm no hangs.
3. Confirm no regressions in the existing SDK test suite.

Scope: small (upgrade + smoke test). Blocking impact: low-probability but process-hang when it hits.
