## Summary

Anthropic SDK 0.129.0 adds a `between_tools` thinking type to message content blocks, representing model reasoning that occurs between tool calls rather than at turn start.

**Impact on Relay:** Relay's thinking-block handling in `claude-sdk.ts` currently processes thinking blocks from the Claude Agent SDK stream. If the SDK forwards `between_tools` blocks that Relay's parser doesn't recognize, they may be silently dropped, displayed as raw JSON, or cause a type error. This is a heads-up for when Relay upgrades `@anthropic-ai/sdk` from 0.109.0.

**Fix:** Before or during the Anthropic SDK upgrade, add handling for `between_tools` thinking blocks — either render them like other thinking blocks or suppress them gracefully.

**Which control this touches:** Thinking-block rendering in `claude-sdk.ts`, thinking UI component.

**Scope:** Small — add a variant branch in the thinking-block handler.
