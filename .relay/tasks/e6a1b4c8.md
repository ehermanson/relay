Agent SDK 0.3.259 adds `permissionPrompts: 'none'` to session options. Unlike `full-access` (which bypasses all permissions and allows everything), this mode auto-denies all permission prompts without disabling auto mode — suited for unattended or scheduled Relay sessions where hanging on an approval dialog is unacceptable but full-access is too permissive.

Relay currently maps `ProviderRuntimeMode` to Claude SDK `permissionMode` values. `permissionPrompts: 'none'` is a session-start arg orthogonal to `permissionMode` — it does not map to an existing mode.

Decision needed:
1. Is this a new `ProviderRuntimeMode` peer value (e.g. `'auto-deny'`), or a boolean session flag alongside an existing mode?
2. Should Relay expose this as a session-level option (per-chat setting) or as a flag on scheduled/background sessions specifically?
3. Add the option to `claude-sdk.ts` session start args once the design decision is made.
4. If a new runtime mode: add to `ProviderCapabilities.runtimeModes`, DB migration, and runtime-mode picker UI.

Scope: small once design is decided (~1–2h). Touch points: `claude-sdk.ts`, `ProviderCapabilities`, `ProviderRuntimeMode`.

Bucket 2 — priority 2.
