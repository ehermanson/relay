Design a multi-machine Relay model where multiple Relay servers can be surfaced in one UI without pretending provider runtimes are portable across machines. Scope should define environment identity, repo identity across machines, chat ownership by environment, merged project/chat views, opening a remote-owned chat from another device, and a safe 'continue here' handoff flow that creates a sibling chat on the local machine instead of migrating the original runtime.
