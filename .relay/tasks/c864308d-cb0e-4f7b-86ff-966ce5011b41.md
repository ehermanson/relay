## Summary

SDK 0.3.287 changes MCP tool results: `structuredContent` exceeding 1,048,576 JSON characters is now omitted with a `structuredContentOmitted: true` flag in its place.

**Impact on Relay:** If Relay renders structured MCP tool results (e.g., in tool-result previews per CLAUDE.md: "Read previews show captured result text"), it may encounter this new shape and either crash, display nothing, or display `structuredContentOmitted: true` as raw text.

**Fix:** Add a guard in MCP tool-result processing that detects `structuredContentOmitted: true` and shows a graceful "result too large to display" message instead.

**Which control this touches:** Tool-result preview rendering, MCP tool-result path in `claude-sdk.ts`.

**Scope:** Small — add a guard and placeholder message.
