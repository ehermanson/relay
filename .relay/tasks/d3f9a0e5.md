Agent SDK 0.3.257 adds `resourceLinks` to tool result messages from MCP servers — structured links (hyperlinks, file paths, resource URIs) the MCP server considers directly relevant to the tool output. These are distinct from the tool result text and represent actionable references.

Relay renders tool results in the chat message view today. `resourceLinks` provides machine-readable links that could be surfaced as clickable buttons (Open File, Visit URL) beneath the tool output text.

Needed:
1. In `claude-sdk.ts`, parse `resourceLinks` from tool result messages and forward through `SessionHistoryEntry`/`ChatMessage` (add an optional `resourceLinks?: Array<{type: string; url?: string; path?: string}>` field).
2. In the JSONL replay path, extract `resourceLinks` from stored tool results.
3. Render clickable link chips below the tool-result text in the chat message component.

Cross-provider normalization: if Codex gains a parallel field, `ChatMessage.resourceLinks` already carries it.

Scope: small (~2h including UI). Touch points: `claude-sdk.ts`, `SessionHistoryEntry`/`ChatMessage`, tool-result renderer, JSONL parser.

Bucket 2 — priority 2.
