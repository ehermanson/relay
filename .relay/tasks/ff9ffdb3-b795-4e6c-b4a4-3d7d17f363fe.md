Codex 0.165.0 shipped a built-in Google Cloud Vertex AI provider, configured by setting `model_provider = "gcp"` in the Codex config. This adds GCP-hosted OpenAI models as a new routing option alongside the default OpenAI API and Azure.

**What Relay needs to do:** expose `model_provider` as a Codex session-creation option in `ProviderCapabilities` so users can select the GCP backend. This is a new session argument that maps cleanly onto the capability-declaration pattern (capability flag + a UI control rendered from metadata). Scope: add a `modelProvider` option to Codex's capability declaration and plumb it through session args, similar to how `reasoningEffort` is handled.

**Touches:** `ProviderCapabilities`, Codex driver session args, UI session-options controls.

**Scope:** medium — a new session arg, a new picker/select in the UI, and a routing entry in the driver.

**Bucket:** capability-declaration (bucket 2).

**Source key:** codex/0.165.0/gcp-vertex-model-provider
