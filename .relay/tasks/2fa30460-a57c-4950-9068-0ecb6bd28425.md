Codex 0.171.0 changed how rollout traces are stored: payloads are now saved in compressed shards. Relay's codex-transcript.ts reads ~/.codex/sessions/*.jsonl rollout files directly for external session discovery, hydration after restart, titles, previews, and agent history. If payloads are now split across or replaced by compressed shard files, the existing line-by-line JSONL parser would silently produce empty or partial results — the same failure mode as the 0.153 event-type rename that broke external session display. Scope: check the new shard storage format in Codex source; update codex-transcript.ts accordingly or add a shard-reader. This is highest-priority: silent empty-chat failures on external Codex sessions. Source key: codex/0.171.0/rollout-trace-compressed-shards.
