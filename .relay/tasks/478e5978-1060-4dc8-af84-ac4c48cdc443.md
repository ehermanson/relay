Codex 0.171.0 added support for specifying a default model provider at the app-server level (not just per-request). Relay currently sets the model on each session but doesn't expose app-server-level provider defaulting. Exposing this via ProviderCapabilities would let the UI pass a preferred model provider (e.g. for multi-provider Codex deployments) at session start rather than relying only on per-turn inference. Scope: check the new app-server option name in Codex source; add it to buildCodexAppServerArgs and expose via session creation options. Source key: codex/0.171.0/default-model-provider-app-server.
