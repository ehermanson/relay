## Summary

Anthropic SDK 0.131.0 explicitly deprecates `claude-sonnet-4-5`. The model remains functional for now but is flagged for removal.

**Impact on Relay:** Relay's `BUILTIN_PROVIDER_MODELS` catalog (`server/core/provider-catalog.ts`) and the model picker UI should mark this model as deprecated to avoid recommending it for new chats. Without this, users may start chats on a model that will be removed, then face a silent breakage.

**Fix:** Add a `deprecated: true` (or equivalent) flag to the Sonnet 4.5 entry in `BUILTIN_PROVIDER_MODELS` and update the model picker to show a deprecation label or exclude it from the default list.

**Which control this touches:** `provider-catalog.ts`, model picker UI.

**Scope:** Small — catalog annotation + picker display logic.
