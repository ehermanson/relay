Claude Agent SDK 0.3.318 added an optional `credential_expires_at` field to result messages (also surfaced as `loginExpiresAt` in `claude auth status`). This field carries the expiry time of the stored claude.ai sign-in. Relay manages auth sessions; having this timestamp on result messages means Relay can detect approaching credential expiry per session without a separate auth probe and warn the user proactively.

Bucket: Capability-declaration (2) — priority 2.

Relay touchpoints: `server/core/providers/claude-sdk.ts` result-message handling, `server/core/providers/claude-cli.ts` auth/account handling, the provider status broadcast (could add an `expiresAt` to `providerGlobalState`), and a UI warning in Settings or the chat header.

Scope: read the field from result messages; propagate to provider status. Small.
