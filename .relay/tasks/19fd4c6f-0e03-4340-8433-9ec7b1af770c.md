Claude Agent SDK 0.3.317 added `onFailure: "block"` to hook matchers. With this option, a hook that throws or returns invalid output blocks the action rather than silently failing. This is a new hook behavior modifier. Relay has hook capabilities surfaced through `ProviderCapabilities`; this new option should be declarable so the UI can offer it and sessions can use it.

Bucket: Capability-declaration (2) — priority 2.

Relay touchpoints: `ProviderCapabilities` hook fields, `server/core/providers/claude-sdk.ts` hook handling, Settings UI hook configuration.

Scope: add `onFailure` to the hook-matcher type/capability; wire through the SDK session args. Small to medium.
