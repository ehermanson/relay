Anthropic SDK 0.118.0 removes the `mid_conv_system` content block type, which allowed injecting a system prompt mid-conversation rather than at session start.

Relay injects structured session bootstrap context (space brief, custom instructions, task guidance) into managed Claude sessions. If any of these injection paths use `mid_conv_system` blocks rather than an up-front system prompt, they would fail on the next SDK pin bump when the type is no longer accepted.

Needed:
1. Check `claude-sdk.ts` and any helper that builds session messages for uses of `mid_conv_system` or equivalent mid-conversation system injection.
2. If found, migrate to the supported mechanism (up-front system prompt or a user-turn context injection).
3. If not found, close this task — it's a no-op.

Note: our SDK deps are pinned, so this is a heads-up for the next upgrade, not a currently-broken state.

Scope: small (audit, ~30 min). Touch point: `claude-sdk.ts`, session bootstrap context helpers.

Bucket 0 — priority 1.

Ref: @anthropic-ai/sdk CHANGELOG v0.118.0 (TypeScript)
