Agent SDK 0.3.307 adds `wakeup_source` to the `command_lifecycle` `started` event frame. It identifies how the session was launched — scheduled wakeup, manual start, etc. — and `scheduled_for` records the scheduled fire time for wakeup-triggered starts. The SDK advertises this via capability `lifecycle_wakeup_source_v1`.

This is a capability-declaration-shaped change: declare support in `ProviderCapabilities` and render it where useful. Concretely:

1. Add `supportsWakeupSource` (or similar) to `ProviderCapabilities`, gated on capability string `lifecycle_wakeup_source_v1` in the `started` frame.
2. In `claude-sdk.ts`, read `wakeup_source` and `scheduled_for` from the `command_lifecycle` started payload and store them on `InstanceInfo` (or a new session-start metadata field).
3. Display the start source in the chat header or session info area — e.g., "Started by schedule" with the scheduled time, as a small badge or tooltip, for scheduled/wakeup-triggered sessions.

This is especially useful alongside the hooks and loop scheduling Relay surfaces elsewhere.

Scope: small (~1.5h). Touch points: `claude-sdk.ts`, `ProviderCapabilities`, `InstanceInfo` type, chat header or session detail UI.
