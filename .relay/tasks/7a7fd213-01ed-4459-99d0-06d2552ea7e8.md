SDK 0.3.330 made query() throw when its settings parameter is a JSON string instead of an object. If Relay (or any helper it calls) serializes session settings to JSON before passing them to query(), the call would error on upgrade. Scope: search claude-sdk.ts and surrounding callers for JSON.stringify applied to settings; confirm settings are always passed as plain objects.
