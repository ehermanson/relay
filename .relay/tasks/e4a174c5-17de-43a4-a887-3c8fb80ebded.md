Codex 0.170.0 removed the legacy sandbox policy setter from the Config object, and 0.171.0 removed the remaining legacy sandbox-policy accessors. Relay's codex app-server session creation (codex-app-server.ts) passes approval policies and sandbox settings to Codex. If Relay used the removed Config setters to configure these, managed Codex session creation would break silently or throw. Scope: audit codex-app-server.ts and buildCodexAppServerArgs for use of removed sandbox policy Config fields; update to the current accessor surface.
