Claude Code CLI 2.1.251 adds a `rate_limits.spend_limit` field to the headless status stream and a spend limit bar to `/usage`. This means the SDK now exposes spending-limit data (dollar cap + current spend) alongside the existing time-window rate limits.

Relay's `ProviderRateLimitStatus` currently models rate limit windows (five_hour, seven_day, model_scoped). Spending limits are a distinct concept — a dollar cap per billing period — that needs a separate field.

Needed:
1. Confirm whether `spend_limit` arrives via the rate_limit_event stream or via the `get_usage` snapshot (check the headless init event and rate_limit_event shape in the installed SDK).
2. Add `spendLimit?: { used: number; limit: number; currency: string }` to `ProviderRateLimitStatus`.
3. Parse it in `claude-sdk.ts` and include in the provider status broadcast.
4. Render a spend-limit bar or row in the sidecar and settings rate-limit UI.

Scope: small–medium (~2h). Touch points: `claude-sdk.ts`, `ProviderRateLimitStatus`, rate-limit UI.
