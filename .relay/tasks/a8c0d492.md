Agent SDK 0.3.246 adds a `costBasis` field to each entry in `modelUsage[]` in the turn result. The field indicates which pricing table was used to compute that model's cost (e.g. `standard`, `batch`, `prompt_cache_write`, `prompt_cache_read`). Previously, cost was a scalar with no indication of how it was calculated.

Relay tracks per-turn costs via `estimateCost` in the session stats path. With `costBasis`, Relay can:
1. Show a breakdown label alongside the cost figure (e.g. "$0.003 via cached reads").
2. Validate that Relay's own cost estimation matches the SDK's reported basis.

Needed:
1. In `claude-sdk.ts`, read `costBasis` from `modelUsage` entries and forward through `SessionStats` (add an optional `costBasis?: string` field).
2. Display the basis in the cost breakdown tooltip or context stats panel.

Scope: small (~1h). Touch points: `claude-sdk.ts`, `SessionStats` type, context sidecar cost display.
