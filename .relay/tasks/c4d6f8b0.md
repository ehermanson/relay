Agent SDK 0.3.238 adds two lifecycle fields to subagent task events:
- `is_backgrounded`: whether the subagent is running in the background (non-blocking)
- `spawn_depth`: nesting depth of the subagent within the agent tree

These fields enrich the existing agent activity data that Relay can forward through `AgentActivity`. They are immediately useful as prerequisites for the nested subagent view design (`803fe57b`) and the agents sidecar enrichment tasks (`ffbc884b`, `f8c1a047`):
- `is_backgrounded` lets the UI distinguish foreground blocking agents from background ones.
- `spawn_depth` enables a tree-indentation scheme in the agents panel without needing to reconstruct the hierarchy.

Needed:
1. Parse `is_backgrounded` and `spawn_depth` from agent lifecycle events in `claude-sdk.ts` and forward through `AgentActivity`.
2. No new `ProviderCapabilities` flag needed — this is data enrichment on the existing agent activity stream.
3. UI rendering is deferred to the agents sidecar design tasks above.

Scope: small (~1h for the parsing + type plumbing). Touch points: `claude-sdk.ts` (agent event handler), `AgentActivity` type.

Bucket 2 — priority 2.
