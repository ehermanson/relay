Agent SDK 0.3.257 adds `thinkingTokens` to the per-model `modelUsage` entries in turn results. We accumulate `input_tokens`, `output_tokens`, `cache_write_tokens`, and `cache_read_tokens` in `SessionStats`; `thinkingTokens` is a new dimension representing tokens consumed by extended thinking that are distinct from regular output tokens.

Needed:
1. In `claude-sdk.ts`, read `thinkingTokens` from `modelUsage` entries in the turn result and accumulate it in `SessionStats`.
2. Add a `thinkingTokens` field to `SessionStats` (or extend the per-model breakdown object).
3. Display it in the Context sidecar panel alongside the other token counts — likely adjacent to output tokens with a clear label.

Scope: small (~1h). Touch points: `claude-sdk.ts` (result handler), `SessionStats` type, context sidecar.

Bucket 2 — priority 2.

Ref: @anthropic-ai/claude-agent-sdk CHANGELOG v0.3.257
