Agent SDK 0.3.283 adds a new `system/informational` message subtype to the stream-json protocol. These carry warnings and notices — soft signals the provider wants to surface (e.g. approaching context limits, rate-limit advisories, deprecation hints) — that are distinct from errors or status messages.

Relay's `claude-sdk.ts` parses system messages by subtype; an unrecognised subtype currently falls through silently. The `system/informational` type should be:
1. Parsed and forwarded as a new `InformationalSystemEvent` (or via an existing `ActivityMessage` variant with `kind: "info"`).
2. Rendered in the chat as a low-prominence notice (similar to how `compaction` notices appear today).

Needed:
1. Identify where Relay handles `system/*` SDK messages in `claude-sdk.ts` and add a case for `"informational"`.
2. Define the data shape (text payload, optional `category`/`severity` fields if the SDK provides them).
3. Route to `ActivityMessage` or a dedicated `InformationalMessage` chat-item type and render as a dismissible status strip or soft banner in the chat.

Scope: small (~2h). ProviderCapabilities field not required — this is a message-handling addition.
