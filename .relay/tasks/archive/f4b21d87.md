Seamless flow to spin up a new chat or space directly from a task card or task drawer, pre-populated with task context.

## Core Flow

- **"Start Chat" button** on task cards (kanban) and task drawer
- **"Start Space" button** on task drawer (creates a space named after the task, seeds first chat)
- Pre-fills composer with `@task:<id>:<title>` reference — not auto-sent, user can add context before sending
- Uses existing `handleCreateChat(initialPrompt?)` pattern and `@task` mention expansion

## UX Enhancements

- **Auto-status update**: optionally set task to `in_progress` when a chat is started from it (toast with undo)
- **Task badge on chat**: if a chat was spawned from a task, show a small task chip in the chat header linking back to the task
- **Linked chats in task drawer**: reverse-lookup chats that reference this task (scan `@task:id` in transcripts or lightweight FK); show as a "Related chats" section in the drawer
- **Task-scoped space**: "Start Space" uses task title as space name/goal, seeds first chat with the task reference

## Entry Points

- Task card: icon button or context menu → "Start Chat"
- Task drawer: explicit buttons in header/action area → "Start Chat" / "Start Space"
- Both should navigate to the newly created chat/space after creation

## Implementation Notes

- Leverage existing custom event pattern (`relay:send-to-new-chat`) or direct navigation with state
- `@task` expansion already gives the model full structured context via XML block
- Chat pre-fill (not auto-send) is consistent with the suggestion actions direction (task c3a7e910)
- Consider: which project context to use if task page is project-scoped vs global
