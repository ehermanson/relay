Add ability from the UI to ignore a 'project' directory. When Claude is run in ad-hoc locations (desktop, config cleanup, etc.), those sessions show up in Relay but aren't meaningful projects. There should be a control (e.g. 'Ignore This Directory' in sidebar context menu) that hides the project and its sessions from the UI. Discovery can still find them initially, but ignored directories should be filtered out of the sidebar and project views. Needs: persistent ignore list (likely in SQLite or a config file), sidebar context menu action, filtering in InstanceManager/API responses, and possibly an 'Ignored Projects' settings view to un-ignore.
