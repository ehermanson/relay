CLI 2.1.223 fixed a bug that hid Claude models registered with gateway-provider prefixes (e.g. `vertex_ai/claude-3-5-sonnet-20241022`, `bedrock/anthropic.claude-3-5-sonnet-20241022-v1:0`) from model discovery. After the fix, these IDs surface in the model picker.

Relay's `formatClaudeModelLabel` in `server/core/providers/provider-catalog.ts` handles `claude-*` IDs. Without a prefix-strip pass, gateway users see raw gateway IDs like `vertex_ai/claude-3-5-sonnet-20241022` in the picker instead of readable labels like "Claude 3.5 Sonnet".

Needed:
1. Strip the gateway provider prefix (`vertex_ai/`, `bedrock/anthropic.`, etc.) before passing the ID to `formatClaudeModelLabel`.
2. Verify model discovery de-duplicates IDs so a model registered under both a canonical and a gateway ID doesn't appear twice.

Scope: small (~1h). Touch points: `provider-catalog.ts` or model discovery in `claude-sdk.ts`.

Bucket 2 — priority 2.
