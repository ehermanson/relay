SDK 0.3.211 added an ISO-8601 `timestamp` field to `SDKAssistantMessage` in the live stream. This is the moment the model completed the message, as opposed to Relay's current processed-at time (when the server received the event).

Relay could:
1. Store the model-completion timestamp on `SessionHistoryEntry` / `ChatMessage` (a new optional `modelTimestamp` field).
2. Display it in a message footer or tooltip as a more accurate "generated at" time — useful for long turns where server-processing lag is noticeable.

Scope: small (~1–2h). Touch points: `claude-sdk.ts` (parse + forward), `ChatMessage` type (add optional `modelTimestamp`), message renderer (display).

Bucket 2 — priority 2.

Ref: @anthropic-ai/claude-agent-sdk CHANGELOG v0.3.211
