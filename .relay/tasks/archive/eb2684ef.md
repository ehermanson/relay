If a user starts a chat on one branch (e.g. main) and at some point switches to some other branch (feature/xyz), we should make sure the user wants to continue the chat on the new branch. 

We need to make sure we're tracking branch name throughout the session though, probably along with 'originalBranchName'. 

This is mostly to help prevent users from doing something on a branch they didn't intend to; bit it also could just lead to confusing conversations with the model if we switch to a totally different branch with a lot of different code/features/whatever mid-conversation.
