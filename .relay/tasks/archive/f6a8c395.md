SDK 0.3.219 adds `fast_mode_disabled_reason` to turn result and session init messages. This string field explains why fast mode is unavailable (e.g., organization policy, plan tier, model incompatibility). Previously the UI could only show that fast mode was off, with no explanation.

Needed:
1. Parse `fast_mode_disabled_reason` from result and init messages in `claude-sdk.ts` and forward it through the provider state broadcast.
2. Surface the reason as a tooltip or subtitle on the disabled fast-mode toggle so users know whether they can address it or not.

Scope: small (~1h). Touch points: `claude-sdk.ts`, `ProviderGlobalState` or instance info type, fast-mode UI component.

Bucket 2 — priority 2.
