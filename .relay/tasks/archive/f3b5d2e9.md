Agent SDK 0.3.232 adds a structured `context_usage` payload (typed as `SDKContextUsage`) to `/context` command result messages, so renderers can display context stats without parsing the markdown output text.

Relay's sidecar context panel currently shows token usage from accumulated session stats. If a user runs `/context` in the composer, the result arrives as an assistant message and Relay renders it as plain markdown. The new `context_usage` field enables a richer, more accurate context stat display tied to a specific point in the conversation.

Needed:
1. In `claude-sdk.ts`, detect the `context_usage` field on `/context` result messages and forward it through the session event stream (e.g. as a new `context_snapshot` event type or appended to the existing stats broadcast).
2. In the sidecar context panel or the message renderer, prefer the structured payload when present for the context ring and token breakdown display.
3. This also provides a natural sync point to refresh the context ring after a `/context` call, replacing the current turn-end polling approach.

Scope: small (~1–2h). Touch points: `claude-sdk.ts` (result handler), `SessionHistoryEntry` or a new event type, sidecar context panel.

Bucket 2 — priority 2.
