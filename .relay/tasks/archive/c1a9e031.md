CoreConfig has claudeDir as a structural field that defaults to ~/.claude. This is used by session discovery, plan loading, and config reading. It should either be optional (only needed when Claude provider is active) or replaced with a provider-agnostic concept like a providerDirs map. The relay should start cleanly without ~/.claude/ existing.
