Provider selection is session-bound, so switching providers should create a new managed session instead of mutating the current one. Add UX in the provider picker that makes the tradeoff explicit, offers to carry over context from the current chat, and boots the new session with portable context (working directory, summary/recent turns, relevant references) rather than provider-native runtime state.
