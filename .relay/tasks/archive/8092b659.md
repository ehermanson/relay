Add UI actions that let the user branch from the current chat into a new work stream without manual copy-paste. Examples include spinning up a new chat from an idea discussed in the current thread, creating a review/test/follow-up chat from the current context, or creating a new space seeded with context from the current chat. Scope should define the user-facing entry points, what context gets carried forward, how much is auto-injected vs editable, and how these branch actions relate to existing spaces and provider handoff behavior.
