Replace the current blunt 3-second `setTimeout → process.exit(1)` shutdown with a proper ordered sequence:

1. Cancel all active turns (flush pending tool responses)
2. Flush state (compact JSONL, WAL checkpoint SQLite)
3. Send SIGTERM to all child processes
4. Wait grace period (~2s)
5. SIGKILL any still-alive children
6. Exit

Also address:
- `codex-app-server.ts` `close()` sends SIGTERM but doesn't await death
- Git subprocesses with 2s timeouts can outlive the server
- No event store compaction or state flush happens on shutdown today
- Add explicit SQLite WAL checkpoint call on shutdown
