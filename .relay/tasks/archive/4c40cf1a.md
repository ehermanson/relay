The relay currently has structural dependencies on ~/.claude/ that run regardless of which provider is being used. These should be abstracted so the relay works cleanly when only Codex (or a future provider) is installed, without requiring Claude Code CLI at all. This epic covers: session/plan discovery tied to ~/.claude/projects/, config reading from ~/.claude.json, and the claudeDir core config concept.
