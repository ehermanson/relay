Anthropic SDK 0.116.0 (TypeScript) adds the advisor tool — a new built-in tool type alongside bash, computer-use, text-editor, and web-search. When Claude uses the advisor tool, it appears in the live message stream and JSONL transcripts as a `tool_use` block with `type: 'advisor'` (or similar).

Relay's JSONL parser and stream handler process `tool_use` blocks. Without an explicit handler, advisor tool blocks may be silently dropped or rendered with a generic fallback.

Needed:
1. Verify the JSONL parser doesn't drop advisor tool blocks — add a case for the new type if needed.
2. Add a render path in the chat message renderer with an appropriate icon and label (consistent with how bash/computer-use/web-search are rendered).
3. Test against a real transcript containing an advisor tool use if available.

Scope: small (~1–2h). Touch points: JSONL parser (`server/core/providers/`), chat message renderer (`app/src/components/chat/`).
