Claude Code 2.1.316 deprecated fast mode for Opus 4.8 as of October 30, 2026, with hard removal on **November 30, 2026**. After removal, fast mode requests for Opus 4.8 will return an error instead of silently falling back to standard Opus 4.8.

**What Relay needs to do:** audit `ProviderCapabilities.fastModes` and the model catalog to ensure Opus 4.8 is not listed as a fast-mode-capable model. If it is, remove it (or add a deadline-driven deprecation notice) before Nov 30. Any UI control that lets users pick Opus 4.8 in fast mode should stop offering it.

**Scope:** small — catalog audit + removal of one model entry. Verify against current `provider-catalog.ts` and `fastModes` in the Claude driver.

**Bucket:** breaking/deprecation (bucket 0) — hard deadline Nov 30, 2026.
