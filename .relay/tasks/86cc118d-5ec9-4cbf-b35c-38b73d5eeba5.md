## Summary

SDK 0.3.286 adds `sdk_mcp_manifests_parked` to the initialize response and new capabilities `sdk_mcp_manifests` and `sdk_mcp_tools_list_changed`. These extend the SDK's MCP manifest management, signaling whether the CLI has parked manifests for later and whether the tool list has changed since last session.

**Impact on Relay:** These new fields extend the MCP capability contract that `ProviderCapabilities.mcp` represents. Relay could surface `sdk_mcp_tools_list_changed` to prompt the user to restart the session if the MCP tool list shifted under them (avoiding stale tool names in the composer), and `sdk_mcp_manifests_parked` to show a loading indicator while manifests are resolving.

**What Relay could do:** Add these fields to the `ProviderCapabilities.mcp` metadata shape and handle them in the MCP state normalization path (`claude-sdk.ts` initialize handler). The UI could show a "Tools updating…" notice when `tools_list_changed` fires.

**Which control this touches:** `ProviderCapabilities.mcp`, MCP state normalization in `claude-sdk.ts`, MCP status UI.

**Scope:** Small-medium — schema addition + initialize handler + optional UI indicator.
