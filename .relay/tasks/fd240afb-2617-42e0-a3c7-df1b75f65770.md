Agent SDK 0.3.295 adds `overageEnabled: boolean` to `SDKRateLimitInfo`. This field tells Relay whether the user's plan has overage enabled — i.e., whether usage can exceed the plan limit (with additional charges) or is hard-capped.

Relay's rate-limit tracking reads `SDKRateLimitInfo` from live `rate_limit_event` messages and from `get_usage` snapshots, merging them in `mergeRateLimitWindows` (`instance-manager.ts`). The merged state is broadcast to the UI and shown in the plan usage display.

Needed:
1. Add `overageEnabled?: boolean` to Relay's internal rate-limit window type (wherever `SDKRateLimitInfo` is mapped/stored — likely `types.ts` or the instance manager's window state).
2. Thread it through `mergeRateLimitWindows` (field-level merge: a defined `true`/`false` wins over `undefined`).
3. Surface it in the plan usage UI — when `overageEnabled` is `true`, show a small indicator that the plan can exceed its cap (e.g. a note next to the utilization bar).

ProviderCapabilities / abstraction: `SDKRateLimitInfo`, rate-limit window state, plan-usage UI component.

Scope: Small (~1h). Touch points: rate-limit types, `mergeRateLimitWindows`, plan-usage UI.
