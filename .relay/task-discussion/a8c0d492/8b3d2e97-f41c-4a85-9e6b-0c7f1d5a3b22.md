Kicked back — needs design decision on the display surface. The SDK field `costBasis?: 'list' | 'managed' | 'unknown'` exists in the installed 0.3.273 SDK and the accumulation into `SessionStats` is mechanical. However, `costBasis` is per-model in `modelUsage`, so a session using multiple models could have different bases for each. Open questions before wiring: (1) Should `SessionStats` carry a single `costBasis` (last-model wins? aggregate?) or a per-model breakdown? (2) Where exactly should it surface in the context panel — a tooltip on the cost figure, a separate row, or a badge? The context panel already shows token counts but cost display varies by setup. Once the display shape is decided, the implementation is straightforward.
