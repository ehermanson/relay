`availableModelsMatch` and `deniedModels` are server-side policy controls
that restrict which models a user can pick. Relay has no "managed settings"
surface yet — there is no existing UI for operators to configure session
policy. Adding this would require designing:
- Where the managed settings configuration lives (project settings? global?)
- How the model picker and `ProviderCapabilities` interact with deny lists
- Whether the scope is per-project or per-account

This is a new surface (bucket-3 territory), not routine capability
plumbing. Leaving status `open` for human design before implementation.
